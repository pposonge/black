검은사막 선원관리 V3.0

기본 구성 및 이용법

[1] 개요

  • 이 도구는 선원 정보를 섹션(구간)별로 관리하며, 각 선원의 레벨별 ‘최고 능력치(베이스)’와 비교해 능력치 차이를 색상으로 표시합니다.
  • 데이터는 브라우저의 로컬 저장소(LocalStorage)에 자동 저장됩니다. 값이 수정되면 약 3초 후 저장되며, 다시 실행 시 이전 상태가 복원됩니다.
  • JSON 파일로 내보내기/불러오기를 지원합니다.

[2] 화면 구성

  • 요약 배지: 전체 보유 선원 수, 주요 섹션(순수, 자신, 현실, 부선장)별 보유 수, 활성 프리셋의 총 선실 수를 표시
  • 프리셋 바: 색상 버튼, 프리셋 선택 드롭다운, [추가] [이름 변경] [삭제] [프리셋 On/Off]
  • 우측 작업 버튼:
    • [상태 보기] — 입력값을 베이스와 비교하여 색상/배지 표시 적용
    • [+ 선원 종류 추가] — 새 섹션(구간) 추가
    • [불러오기] — JSON 선택 후 상태 복원
    • [저장하기] — 현재 상태를 JSON 다운로드
    • [완전 초기화] — 저장 데이터 삭제(새로고침 필요)
    • [모드 전환(◑)] — 라이트/다크 모드 전환

[3] 프리셋 사용법

  • 프리셋 최대 10개, 이름은 최대 6자.
  • 프리셋 On 상태에서 정렬 시 ‘탑승(★)’ 지정 선원이 우선 표시됩니다.
  • 각 선원 행의 ★ 버튼으로 활성 프리셋 기준 탑승/미탑승을 토글합니다(★/☆).

[4] 섹션(구간) 관리

섹션은 선원 그룹(예: 순수, 자신, 현실, 부선장 등)을 나타냅니다.

  • [선원 추가] — 입력 표에 행 추가
  • [⚙️ 능력 설정] — 능력치 열 관리(이름/표시 여부/추가/삭제)
  • [⚙️ 베이스 설정] — 레벨 범위(1~20) 재지정
  • [이름 변경] — 섹션 이름 변경
  • [삭제] — 섹션 제거(2개 이상일 때 표시)
  • [확인 해제] — 이 섹션의 모든 행 ‘확인’ 표시 일괄 해제

섹션 요약: “선원 수 X / [활성 프리셋명] Y - 선실 Z(= 섹션 선실값 × 탑승 수)”.

[5] 표 사용법

  • [선원 입력] 열: 이름 / 레벨(1~20) / 탑승(★/☆) / 능력치들 / 작업(삭제, 확인)
  • 선원 레벨 입력 시 1회성으로 베이스 레벨이 자동입력됨
  • 능력명 클릭으로 정렬(이름, 레벨, 능력치). 프리셋 On이면 탑승 선원 우선 정렬.
  • [확인] 클릭 시 해당 행 강조(토글). 상단 [확인 해제]로 일괄 해제.
  • [선원 최고 능력치] 표에서 레벨별 기준값(베이스) 입력/수정.

[6] 능력/베이스 설정

능력 설정

  • 항목명 텍스트 수정 및 표시/숨김 전환
  • [속성 추가]로 열 추가, [선택 삭제]로 체크된 열 삭제(입력/베이스 표 모두에서 제거)
  • [저장] / [취소] 제공

베이스 설정

  • 시작/끝 레벨(1~20) 지정 → 지정 범위로 레벨 행 재구성
  • 기존 범위에 있던 레벨의 값은 가능한 경우 유지

[7] 상태 보기 (색상 비교 규칙)

  • 형광색 +Δ: 입력값 > 기준값
  • 초록색: 입력값 = 기준값
  • 분홍색 Δ: 입력값 < 기준값
  • 표시 중인 모든 능력치가 기준보다 높으면 해당 행의 레벨 셀에 노란색 강조 표시

[8] 선실 계산 규칙 (섹션명 → 1인당 선실)

아래 이름이 정확히 일치할 때만 선실이 계산됩니다(불일치 시 0).

터프 5 / 경험 10 / 똑똑 5 / 보물 5 / 끈기 5 / 자신 5 / 계산 10 /
사랑 10 / 순수 10 / 욕심 10 / 바다 10 / 성실 10 / 우직 7 / 힘 8 /
강인 8 / 만선 13 / 호기심 10 / 재빠른 10 / 현실 10 / 부선장 10

[9] 데이터 관리

  • [저장하기]: 현재 상태를 JSON 파일로 다운로드
  • [불러오기]: JSON 파일로 저장된 상태 복원(형식 오류 시 안내)
  • [완전 초기화]: 로컬 저장소 데이터 삭제(이후 새로고침 필요)

[10] 모드 전환

[◑] 버튼으로 라이트/다크 모드 전환(브라우저에 기록되어 다음 방문 시 유지)
